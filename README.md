# ShopSphere 🛒

ShopSphere is a Django-based e-commerce web application developed as a practice and portfolio project.

## ✨ Features

* User Registration and Login
* Password Reset
* Change Password
* Product Browsing
* Product Search
* Product Categories
* Trending Products
* Special Offers
* Product Details
* Add to Cart
* Quantity Management
* Remove from Cart
* Buy Now
* Checkout
* Order Placement
* My Orders
* User Profile
* Profile Update
* Profile Picture Upload
* Password Show/Hide
* Support and About/Know Us pages

## 🛠️ Tech Stack

* **Python**
* **Django**
* **SQLite**
* **HTML**
* **CSS**
* **JavaScript**
* **Bootstrap**

## 🔐 Security

Sensitive configuration such as the Django `SECRET_KEY` is stored using environment variables and is not included in the repository.

The project also excludes:

* `.env`
* `db.sqlite3`
* Virtual environment files
* Python cache files
* Sensitive personal files

through `.gitignore`.

## 🎯 Project Purpose

ShopSphere was created to practice and demonstrate Django concepts such as:

* Django Models

* Authentication
* Sessions
* CRUD Operations
* Templates
